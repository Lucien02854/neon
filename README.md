# Neon
Neon, formerly known as VOS (Virtual Operating System) is a python-coded program laid out into many files and folders for modularity. This is based off VOS, but more refined and with a completely new look (don't let the name fool you, it doesn't look like a glowstick). It has it's own API (Neon Library) for building your own apps for Neon, which you can do if you already know python coding and have a text editor.
(VOS apps WILL NOT work correctly on Neon)
