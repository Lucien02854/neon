# Neon
Neon, formerly known as VOS (Virtual Operating System) is a python-coded program laid out into many files and folders for modularity, using tkinter/customtkinter to behave like an operating system. This is based off VOS, but more refined and with a completely new look (don't let the name fool you, it doesn't look like a glowstick). It has it's own API (Neon Library) for building your own apps for Neon, which you can do if you already know python coding and have a text editor
(VOS apps WILL NOT work correctly on Neon). To get started, open the VHDX file provided, navigate to the boot folder, open launch.py, click the ">" button at the bottom, and type "help". Python 3.9 is required for Neon to work fully functional, make sure when installing python 3.9 to enable the checkbox labeled something like "Add python 3.9 to PATH". Neon is meant to be ran on Windows, other platforms may not work correctly for Neon.
